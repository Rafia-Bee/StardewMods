[size=4][b]What does this mod do?[/b][/size]

If you use the [url=https://www.nexusmods.com/stardewvalley/mods/43136]Deluxe Grabber Reduxe Fixes[/url] mod, you probably faced the issue of the auto-grabber overflowing and having to press the global grabber button multiple times to gather all the items. This mod expands the auto-grabber's internal chest beyond the vanilla 36-slot limit, so the deluxe grabber can grab everything in one go.

[b][u][color=#a64d79][size=4]Update on v2.0.0: Now this mod also lets you make your storage bigger too![/size][/color][/u][/b]

You can set a different size for each kind of storage:
[list]
[*][b]Auto-grabbers[/b]: pairs great with mods like [url=https://www.nexusmods.com/stardewvalley/mods/20799][/url][url=https://www.nexusmods.com/stardewvalley/mods/43136]Deluxe Grabber Reduxe Fixes[/url] that dump a lot of items at once[/*]
[*][b]Chests[/b]: regular, big, stone, junimo and modded chests[/*]
[*][b]Fridges[/b]: the kitchen fridge and mini-fridges[/*]
[/list]

[size=4][b]Features[/b][/size]
[list]
[*][b]One default plus per-type sizes[/b]: set a single default for everything, or give any specific kind of storage its own size, from 36 (vanilla) up to 516[/*]
[*][b]Modded chests too[/b]: chests added by other mods get their own row automatically[/*]
[*][b]Leave anything at 36[/b] to keep that storage normal[/*]
[*][b]Safe to install and uninstall[/b]: no items are ever deleted. Removing the mod puts everything back to 36 slots; items in the extra slots stay in your save and come back if you reinstall[/*]
[/list]

[size=4][b]Configuration[/b][/size]
If you have [url=https://www.nexusmods.com/stardewvalley/mods/5098]Generic Mod Config Menu[/url] installed, you can change the sizes from the in-game options screen. Otherwise, edit [font=Courier New]config.json[/font] in the mod folder.
[list]
[*][b]Default size (everything else)[/b] (default: 36). Used for any storage that doesn't have its own row, including modded chests you haven't set.[/*]
[*][b]A row per storage type you own[/b]: auto-grabber, fridge, mini-fridge, regular chest, stone chest, big chest, junimo chest, and any modded chests. Set a row to give just that type its own size; leave it on the default and it follows the default.[/*]
[/list]
New storage types show up as rows once you load a save that has them. If you uninstall a mod that added a chest, its row clears itself out next time you load. Everything runs from 36 to 516 in steps of 12, or type any value by editing [font=Courier New]config.json[/font] directly.

[size=4][b]Good to know[/b][/size]
[list]
[*]The storage window shows up to 72 slots (6 rows) at a time. If you set a size higher, you can scroll through the rest with the mouse wheel or the up/down arrows on the right side of the grid.[/*]
[*]If you set a size below what's already stored, those extra items stay safe in your save. They just hide until you make it bigger again.[/*]
[*][b]Will clash with any mod that expands vanilla chest capacity.[/b][/*]
[/list]
