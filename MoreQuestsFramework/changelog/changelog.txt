To be released
- For mod authors: quest categories are now open-ended. Recolor the nine built-in categories or add your own, each with its own note colors and the skill it scales with, by editing the new Categories asset from a Content Patcher pack or calling RegisterCategory in C#.
- For mod authors: custom board quests now go to one board by id, so one mod's board quests no longer show up on another mod's board. A quest picks its board with the new "CustomBoardId" trigger field, or leaves it out to use your mod's only board.
- For mod authors: a board can now be a catch-all that also shows quests from other mods, set with the new "AllowedOwners" field.
- For mod authors: "OverrideTriggerSource" has a new form that also names the target board, for sending a quest that has no board of its own onto your board.

2.7.0
- The help-wanted board now shows your prize ticket stars as soon as you open it, instead of only after you click a quest note. Hovering the stars tells you how many more quests you need before your next prize ticket.
- Fixed the quest board's hover tooltip showing words like "Deliver", "Collect", and "Slay" in English even when you played in another language. They can now be translated, along with the catch-all item names (like "fish" or "metal bar") that show when a quest asks for any item of a type.
- For mod authors: a new "earn money" quest type. It asks the player to earn a set amount of gold and finishes on its own, counting only from the moment it started so money they already had doesn't count.
- For mod authors: a new "sell to a shop" quest type. It counts items the player sells over a chosen shop's counter, like Pierre's or Joja's, and can be narrowed by item type, price, and quality. The items still sell as normal.
- For mod authors: a quest that fires once can now trigger the first time the player has earned a set amount of gold across their whole save.
- For mod authors: a reusable "deposit box" you can hook up to a quest step. It opens the same drop box window the game uses for community center style donations, you decide which items it takes, and the step counts up for each item dropped in. It comes with the bobbing "!" marker so you can flag where the box is.
- For mod authors: a new "craft" step type. It counts the player crafting a set item (matched by item id or by a context tag, so "any sign" works) and reads the game's own crafting counter, so it counts no matter which crafting menu is used, including Better Crafting. A spawned-in item never counts.
- For mod authors: a way to check how many quests are still up on the help-wanted board and not yet taken. Handy if your mod shows a "new quest" marker and wants to hide it once the board is cleared. There's also a new "mq_boardcount" console command that prints the count and lists what's left.

2.6.0
- For mod authors: a "slay monsters" step can now require the kills happen on a set range of mine floors, covering both the Mines and the Skull Cavern.
- For mod authors: quests can now end with the player reporting back to a villager and picking from a few answers, where the answer they choose decides the reward. Register the question and answers with the new RegisterReportBackChoice and point a Custom step at it. See the README for an example.
- Fixed a quest that a villager only offers during a set range of days showing up after that range was over. If you hadn't talked to them during the window, the quest could pop up the next time you chatted, even days later. Now it's quietly dropped once the window passes. (For example, a quest Vincent only gives during the Egg Festival days no longer appears if you talk to him afterward.)
- For mod authors: a quest can now show more than one objective line at once, handy for a checklist-style job or showing something like a running budget. The Quest Journal mod shows these lines too.
- For mod authors: a quest can now say which villagers are allowed to give it, and there's a new console command to check. Run "mq_givers <quest id>" to print who's eligible for that one, or "mq_givers all" to write a file listing every quest and its eligible givers (named after your save) into the framework's mod folder. Good for testing.

2.5.0
- The help-wanted board got a tidy-up. The notes used to scatter and pile on top of each other, so when a lot of quests were up some ended up buried and hard to click. Now they sit on a neat layout that fits every note no matter how many are posted, and each one is easy to pick on mouse or controller. They still get a slight random lean so it looks like a real cork board.
- You can now pick jobs on custom boards (like the Adventurer's board) with a controller. Before, the controller couldn't select anything on those.
- Two new settings for the help-wanted board: note spacing (how far apart the notes sit, or set it low to let them overlap a little) and biggest note size (how large a note gets when only a few are posted).

2.4.0
- Added a tool for mod authors that tells you the exact item a quest wants handed in, with the quality and how many are still needed, and resolves "any of these" item lists to a real item. The Quest Journal mod uses this for its "get quest item" helper. No in-game change on its own.

2.3.0
- New step kind for mod authors: "decorate a room". It counts furniture the player puts down in a named building while the quest is going. Only new pieces count, so moving furniture around or anything already in the room won't tick it up. Authors can ask for a specific kind (a rug, a light, a wall piece, or anything else), which makes "place a rug, a lamp, and a painting" quests easy to set up.
- New quest start for mod authors: fire a quest the first time the player reaches a heart level with an NPC (for example, 5 hearts with Emily).
- New step kind for mod authors: "drop items inside a marked circle". The game draws a glowing ring on the ground with a tall beam of light above it so the player can find the spot, and only items dropped inside the ring count. The marker is purely visual: it never blocks anyone or harms anything placed there, so people and monsters walk right through it. Comes with a new magic-themed NPC pool for quest givers.
- New tools for mod authors who want to add quests that track crop growing. There's a new event that fires every time a crop is harvested (by you or your Junimos), and a new way to dedupe step progress per tile / per event so the same thing can't double-count.
- New farmer NPC pool so quests can pick a farmer NPC as the giver. Covers Pierre, Evelyn, Andy / Sophia / Susan from SVE, Jeric / Alissa from Ridgeside, Jessie from East Scarp, Ashida / IsaacI from Coal Point Farm, and Ripley.
- Fixed a rare issue where a basic vanilla-style quest (the simple "deliver this" / "catch that" / "slay that monster" / "collect this" jobs) could be lost if you saved and reloaded the game in between getting the mail letter and opening it. Only affected the cases where a quest landed in your mail because its giver was on the exclusion list.
- Mail quest chance sliders in GMCM actually work now. Before this only Rainy Day Catch responded to its slider; every other entry was a no-op. Quests that only fire once on a building going up (Marnie's first chicken / cow / silo offers) are hidden from the page so you can't accidentally lose one by turning the slider down.
- Filled in two missing GMCM labels (Crop Cycle delivery, Archaeology dig) that were showing as raw IDs.
- Reworked how custom boards (like the Adventurer's board) sit and draw in the world. They no longer paint on top of you when you stand in front of them, the part you bump into now matches exactly what you see, and you stand on the open tile right in front of the board. Authors place a board by its floor tile and a size in tiles, no more fiddly pixel offsets.
- Hovering a quest on a board now shows what it wants (the action and the items) instead of a raw internal name.
- Fixed adventure-board quest pop-ups running off the parchment when you use a custom font.
- The Dwarf no longer posts town help-wanted quests. He lives in the mines, so a town errand from him read wrong.

2.2.0
- Fixed a bug where some quest rewards (friendship, items, etc.) could get duplicated each time you saved and reloaded. Old saves with the bug get cleaned up automatically the next time you load them.
- Added new tools for mod authors who want to build richer quest journal screens. No in-game change on its own.

2.1.1
- Fixed a bug where finishing a ship quest could max out a villager's friendship in one go. Only happened on saves where the quest was accepted on an older version of the mod and finished after updating. Affected saves now pay the right amount when the quest wraps up.

2.1.0
- Difficulty Scaling now defaults to off. Flip it on in GMCM if you want quests to scale with your skill levels.
- New step kinds for adventure quests: dig artifact spots, drop items, donate to museum.
- Dialog-triggered quests can now have the giver actually say the offer line in person.
- New per-quest friendship reward line, plus 5 kid dialog variants for friendlier rewards.
- New helper for mods to list all installed tackles.
- Mail-fallback daily-board quests no longer re-roll a new quest every day.
- Long quest descriptions no longer overflow the daily Billboard panel.
- Fixed cooldown not stamping in some cases, and the cooldown queue is re-applied after a save reload.
- Fishing report-back quests no longer eat the fish on turn-in.
- Fishing delivery quests say "Deliver X to Y" instead of "Return to NPC".
- Rainy Day Catch chance moved here from More Quests so framework content packs can tune it.
- New mq_trigger console command to force a quest to post (for testing).

2.0.0
- Switched to Content Patcher for adding quests. The old "make a folder with a quests.json" path is gone. CP packs now edit Mods/RafiaBee.MoreQuestsFramework/Quests directly, and authors get When conditions, dynamic tokens, patch reload, and the patch summary debug command for free.
- Same story for custom boards (Mods/RafiaBee.MoreQuestsFramework/Boards) and cooldown buckets (Mods/RafiaBee.MoreQuestsFramework/CooldownTiers).
- GMCM edits to cooldown tier days now take effect mid-session, no save reload needed.
- C# mods that used to call LoadQuestsFromMod / LoadBoardsFromMod / LoadContentPack should subscribe to AssetRequested and edit the assets instead. See docs/example-csharp-generators/ for the pattern.
- Migration steps for 1.x packs are in the README under "Migrating a 1.x consumer to 2.0".
- Catchable fish lookup now honors the per-spawn Season field, not just the GSQ Condition string. Fixes legendaries (like Angler) being treated as catchable outside their actual season.
- Catchable boss-fish lookup now excludes Mr. Qi's extended-family legendaries (Ms. Angler, Son of Crimsonfish, Glacierfish Jr., Radioactive Carp, Legend II, plus any modded analog that gates on the same family rule).
- New QuestContext.IsItemRecent helper so generators can skip a target the framework just used. Same anti-repetition queue the framework was already keeping; just exposed.
- Added a built-in cooking-skill detector that recognises both Love of Cooking and YACS / Cooking Skill Redux, and reads the level from whichever is installed. The "Cooking N" SkillLevel condition picks up both automatically.
- Fixed the Skull Cavern Deep Dive and Mines Deep Dive quest weight labels missing from the GMCM Mining page (post-CP-migration regression).

1.1.0
- Added controller support for the custom quest billboard so D-pad can move between notes and accept quests.
- Added controller support for the Prev/Next pager buttons on the Special Orders board.
- Added a GMCM "Excluded quest givers" field so the IneligibleGivers list can be edited in-game.
- Added a MailFallbackForExcludedGivers toggle. When a daily-board quest's hardcoded giver is excluded, the quest gets redirected to mail (or dropped if the toggle is off) instead of silently disappearing.
- Added per-category pad/pin tinting on the cork-board so each of the 9 quest categories has its own color (was 5 by quest type before).

1.0.0
- Initial public release.
- Multi-slot Help Wanted billboard, replaces vanilla's single Quest of the Day.
- Optional paginated Special Orders board (up to 5 pages).
- Daily generation pipeline with weights, cooldowns, per-NPC dedup, and friendship-cap dedup.
- Trigger sources: DailyBoard, Mail, Periodic, DateLocked, DateRange, OneShot, BuildingBuilt, MailReceived, WeatherForecast, NpcDialogue, SpecialOrder, CustomBoard.
- Custom boards (per-location pin-boards) registered via BoardDefinition + boards.json.
- Reward kinds: Money, Friendship, Object, Recipe, Mail (Today / Tomorrow / NextDay), ShopDiscount, AnimalPurchaseDiscount, FestivalBias, FairStarTokens.
- Consequence engine with Tier1 / Tier2 / Tier3 / Special tiers, persistent dialogue queue, configurable grace window.
- AdventureQuest base class with Deliver, Talk, Gift, GiftUniqueNpcs, Ship, Catch, Slay, ReachLevel, Visit, Build, Plant, Collect, ClearWeeds, ClearDebris, Custom step kinds.
- Decor-shipping bypass for quests that ask the player to ship furniture or decor.
- Condition evaluator covering season, date, weather, skill, friendship, mail flag, building, mod presence, GSQ, and more.
- Public API for registering quests, generators, custom quest types, reward kinds, conditions, consequences, dispatch NPCs, and combat foods.
- SMAPI content-pack loader (auto-loads any pack with ContentPackFor = RafiaBee.MoreQuestsFramework).
- Four configurable vanilla wrappers: VanillaItemDelivery, VanillaResourceCollection, VanillaSlayMonster, VanillaFishing.
- Per-quest weights, friendship reward sizes, gold tiers, reward multipliers, and deadline lengths exposed through GMCM.
