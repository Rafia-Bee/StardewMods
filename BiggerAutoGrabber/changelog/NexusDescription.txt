[size=4][b]What does this mod do?[/b][/size]

If you use mods like [url=https://www.nexusmods.com/stardewvalley/mods/20799]Deluxe Grabber Redux[/url], you've probably run into the auto-grabber overflowing its 36-slot chest. This mod lets you expand that capacity so the grabber can collect everything in one go, no more mashing the global-grab button.

[size=4][b]Features[/b][/size]
[list]
[*][b]Configurable capacity[/b]: Set the auto-grabber's internal chest anywhere from 36 (vanilla) up to 288 slots via the config menu, or any custom value in [font=Courier New]config.json[/font][/*]
[*][b]Works with any auto-grabber mod[/b]: Deluxe Grabber Redux Fix, or anything else that uses auto-grabbers[/*]
[*][b]Applies everywhere[/b]: All existing and newly placed auto-grabbers get the expanded capacity[/*]
[*][b]Safe to install and uninstall[/b]: No items are ever deleted. Removing the mod simply reverts auto-grabbers to the vanilla 36 slots; items in extra slots persist in your save and become accessible again if you reinstall[/*]
[/list]

[size=4][b]How it works[/b][/size]

The mod uses a Harmony patch on the auto-grabber's internal chest to override its capacity. Each auto-grabber chest is tagged with mod data on save load, day start, and whenever a new auto-grabber is placed, so the patch knows which chests to expand.

[size=4][b]Configuration[/b][/size]
If you have [url=https://www.nexusmods.com/stardewvalley/mods/5098]Generic Mod Config Menu[/url] installed, you can change the capacity from the in-game options screen. Otherwise, edit [font=Courier New]config.json[/font] in the mod folder.
[list]
[*][b]Capacity[/b] (default: 36). Number of item slots in each auto-grabber. The config menu slider goes from 36 to 288 in increments of 12. You can set any value you like by editing [font=Courier New]config.json[/font] directly.[/*]
[/list]

[size=4][b]Good to know[/b][/size]
[list]
[*]The in-game chest UI displays up to 72 slots (6 rows) at a time. If you set the capacity higher, you can scroll through all your items using the mouse wheel or the up/down arrows on the right side of the grid.[/*]
[*]If you reduce the capacity below the number of occupied slots, items in the extra slots stay in your save: they just won't be visible in the UI until you increase the capacity again.[/*]
[*]This mod has no effect on regular chests: only the internal chest inside auto-grabbers.[/*]
[/list]

[size=4][b]Compatibility[/b][/size]
[list]
[*][b]Custom Chest Size[/b] by Kree: When Custom Chest Size is installed, Bigger Auto-Grabber detects it and steps aside so the two mods don't fight over the menu layout. Auto-grabber sizing is then handled entirely by Custom Chest Size.[/*]
[/list]
