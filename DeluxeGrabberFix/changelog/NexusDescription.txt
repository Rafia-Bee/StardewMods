[size=4][b]Credits & History[/b][/size]
I decompiled the Deluxe Grabber Redux 1.6 mod by Nykal145, who had updated the original Deluxe Grabber Redux by ferdaber to work with the Stardew Valley 1.6 update.

The base code and functionality credits go to [url=https://www.nexusmods.com/profile/Nykal145]Nykal145[/url] and [url=https://www.nexusmods.com/profile/igrek312]ferdaber[/url]. I couldn't have made the fixes and feature additions without their hard work.

[size=4][b]What does this mod do?[/b][/size]
Deluxe Grabber Fix supercharges the vanilla auto-grabber to collect crops, fruit, forage, animal products, and much more. Place an auto-grabber on any map and it handles the harvest for you.

This is a bugfix-and-feature fork of Deluxe Grabber Redux 1.6. It fixes a bunch of bugs (including item loss, crashes with modded content, and performance issues on large farms and modpacks) and adds new features like per-location filtering and festival item grabbing toggles. Pre-existing features like animal product collection and global grabber modes have been fixed to work properly.

[b]If you run into any bugs or have feature requests, please report them on this mod's page, not Nykal's, so I can track and fix them![/b]

[size=4][b]Features[/b][/size]
[list]
[*][b]Crop harvesting[/b]: Harvests ground crops and indoor pot crops within a configurable range and shape (diamond or square). Fully delegates to the game's own harvest logic, so modded crops, quality overrides, and extra harvest chances all work correctly.[/*]
[*][b]Fruit trees[/b]: Picks fruit from mature fruit trees, including quality based on tree age.[/*]
[*][b]Berry bushes[/b]: Collects berries from salmonberry and blackberry bushes.[/*]
[*][b]Seed trees[/b]: Shakes trees for seeds, hazelnuts, coconuts, and other drops. Uses the game's own shake logic, so modded trees work too.[/*]
[*][b]Tree moss[/b]: Strips moss from trees.[/*]
[*][b]Animal products[/b]: Collects milk, wool, eggs, feathers, and other animal products from barns and coops: just like the vanilla auto-grabber does, but extended to work with the global grabber system.[/*]
[*][b]Slime balls[/b]: Collects slime balls in slime hutches.[/*]
[*][b]Farm cave mushrooms[/b]: Grabs mushrooms from cave boxes (works anywhere you place them). Configured under the Machine Collection page.[/*]
[*][b]Artifact spots[/b]: Digs up artifact spots for loot.[/*]
[*][b]Ore panning[/b]: Collects ore from panning sites.[/*]
[*][b]Seed spots[/b]: Digs up raccoon seed spots.[/*]
[*][b]Hardwood stumps[/b]: Fells large stumps and hollow logs for hardwood in all locations.[/*]
[*][b]Town garbage cans[/b]: Searches garbage cans for items.[/*]
[*][b]Forage[/b]: Picks up all forageable items (truffles, beach forage, etc.) with quality based on your foraging skill. Also collects modded spawned forage.[/*]
[*][b]Item debris[/b]: Collects items dropped as ground debris: monster loot, fallen items, and modded forage drops (e.g. Twilight Feathers from Sunberry Village).[/*]
[*][b]Exclude quest items[/b]: Prevents the grabber from collecting quest items like the Lucky Purple Shorts. Enabled by default.[/*]
[*][b]Item exclusion list[/b]: Specify items by their qualified item ID that the grabber should never collect, so rare finds like the Lucky Ring don't pile up.[/*]
[*][b]Machine collection[/b]: Automatically collects finished outputs from all vanilla machines: Crab Pots, Bee Houses, Tappers, Heavy Tappers, Mushroom Logs, Leaf Baskets ([url=https://www.nexusmods.com/stardewvalley/mods/39216]Cloths and Colors[/url]), Fish Ponds, Mushroom Boxes, Kegs, Preserves Jars, Cheese Presses, Mayonnaise Machines, Looms, Oil Makers, Furnaces, Charcoal Kilns, Recycling Machines, Seed Makers, Bone Mills, Geode Crushers, Wood Chippers, Deconstructors, Fish Smokers, Bait Makers, Dehydrators, Crystalariums, Lightning Rods, Worm Bins, Solar Panels, Slime Egg Presses, Coffee Makers, Soda Machines, and statues (Endless Fortune, Perfection, True Perfection). Also collects from modded machines via an "Other Machines" toggle. Every machine toggle is on by default; flip "Disable Machine Collection" in GMCM if you want to stop all machine collection at once.[/*]
[*][b]Yield reporting[/b]: Logs what each auto-grabber collected to the SMAPI console. Also shows an in-game HUD toast after daily and global grabs.[/*]
[*][b]Chest-full warnings[/b]: Shows a red HUD warning when auto-grabber chests are full so you never silently lose items.[/*]
[*][b]Replant reminder[/b]: When single-harvest crops are collected, a HUD notification reminds you to replant. A second reminder fires later in the day at a configurable time (default 8:00 PM) so you don't forget on busy days.[/*]
[*][b]Auto-grabber naming[/b]: Name individual auto-grabbers through the Name button on the auto-grabber menu. Named grabbers show their name in chest-full warnings and grab summary toasts. Also reads names set by Chests Anywhere as a fallback.[/*]
[*][b]Experience gain[/b]: Earn farming and foraging XP as if you harvested everything yourself. Also routes XP to [url=https://www.nexusmods.com/stardewvalley/mods/14073]Binning Skill[/url] (per garbage can checked) and [url=https://www.nexusmods.com/stardewvalley/mods/22199]Archaeology Skill[/url] (per artifact spot dug and ore pan collected) when those mods are installed.[/*]
[*][b]Global grabber[/b]: Make one auto-grabber collect from all locations at once. Designate your global grabber by opening it and tapping the star button (works on mobile!), or use the classic hover + hotkey method on PC. Optionally auto-fires every morning.[/*]
[*][b]Per-save config[/b]: Each save file gets its own independent config. Changing settings in one save won't affect your other saves. The global config.json is used as the template for new saves.[/*]
[*][b]Location filtering[/b]: Skip festival areas automatically, and choose exactly which locations the grabbers should ignore via a config menu page.[/*]
[*][b]Select Visited Only[/b]: A toggle on the Enabled Locations page that enables only locations you've actually visited, skipping the rest. Newly discovered locations are auto-enabled when you walk into them.[/*]
[*][b]Specialized Grabbers[/b]: An optional progression system that replaces the "one grabber does everything" model with six specialized grabbers, each collecting a specific category of items. [url=https://www.nexusmods.com/stardewvalley/articles/4322]Read more about specialized grabbers here.[/url][/*]
[/list]

[size=4][b]Specialized Grabbers[/b][/size]
An optional feature controlled by the [font=Courier New]GrabberMode[/font] config setting. Switch from Classic (default, one grabber does everything) to Specialized to unlock a progression chain of six grabbers, each handling a specific category. For a full guide with images, [url=https://www.nexusmods.com/stardewvalley/articles/4322]check out the Specialized Grabbers article[/url].
[spoiler]
[b]The Six Grabbers[/b]
[list=1]
[*][b]Animal Grabber[/b]: Collects milk, wool, eggs, slime hutch items. This is the vanilla auto-grabber you buy from Marnie.[/*]
[*][b]Crop Grabber[/b]: Collects crops, indoor pots, and seed spots. Unlocked after shipping 200 crops.[/*]
[*][b]Forage Grabber[/b]: Collects forage, berries, moss, spring onions, and cave mushrooms. Unlocked after foraging 200 items.[/*]
[*][b]Tree Grabber[/b]: Collects fruit trees, seed trees, and hardwood stumps. Unlocked after chopping 50 stumps.[/*]
[*][b]Scavenger Grabber[/b]: Collects artifact spots, debris, garbage cans, panning, and green rain weeds. Unlocked after donating 15 museum items.[/*]
[*][b]Machine Grabber[/b]: Collects machine outputs, crab pots, and fish ponds. Unlocked after earning 250,000g total.[/*]
[/list]

[b]Progression[/b]
Grabbers unlock sequentially. You must own the previous grabber and meet a gameplay milestone to unlock the next one. The day after you acquire a grabber, you receive a hint mail about what to work toward. When you meet the milestone, you get the crafting recipe in the mail. All milestones and crafting costs are configurable.

[b]Global Grabber in Specialized Mode[/b]
Global Grabber is not disabled. In All mode, every grabber collects its assigned category from all enabled locations automatically. In Hover mode, point at a grabber and press the fire key to collect from all locations. In Off mode, grabbers collect locally only.

[b]Mode Switching[/b]
Switching between Classic and Specialized is safe at any time. In Classic mode, all grabbers (including specialized ones) collect everything. In Specialized mode, each grabber only collects its assigned category. No objects are converted or destroyed.[/spoiler]

[size=4][b]Bug Fixes (vs. Deluxe Grabber Redux 1.6)[/b][/size]
I went through the posts and bug reports on [url=https://www.nexusmods.com/profile/Nykal145]Nykal145[/url]'s mod page and tried to fix every issue I could find. If you've used the original mod, you may have run into some of these, they're all fixed here:
[spoiler]
[list]
[*][b]Items vanishing[/b]: When an auto-grabber's chest filled up mid-batch, remaining items from that source (slime ball, crop, stump, etc.) were permanently lost. Fixed: sources are only consumed when all items fit.[/*]
[*][b]Fruit tree fruit loss[/b]: If a tree had 3 fruits and only 2 fit in the chest, all 3 were cleared. Fixed: each fruit is removed individually as it's stored.[/*]
[*][b]Crash on modded artifact spots[/b]: Artifact spots that drop Rings, Boots, or Weapons crashed with InvalidCastException. Fixed: all item types are accepted.[/*]
[*][b]Crash on modded bushes[/b]: Bushes returning null from GetShakeOffItem() crashed the entire grab cycle for that location. Fixed: null/empty shake-off IDs are handled gracefully.[/*]
[*][b]Crash on modded crops[/b]: Crops with null/empty harvest IDs crashed with ArgumentNullException or KeyNotFoundException. Fixed: crop harvesting now uses vanilla logic directly.[/*]
[*][b]Tree corruption from moss harvesting[/b]: Harvesting moss set the tree's growth stage to invalid values, visually regressing fully-grown trees. Fixed: only the moss flag is cleared, matching vanilla behavior.[/*]
[*][b]Zero-item artifact drops[/b]: A random roll could produce 0 copies of a valid drop, silently discarding it. Fixed: minimum 1 copy is always produced.[/*]
[*][b]Global grab firing on day start[/b]: All mode triggered global collection every morning and on every object change, not just on button press. Fixed: global mode only activates when you press the fire key.[/*]
[*][b]Performance cascade on large farms[/b]: Removing objects during a grab triggered additional grab cycles in a feedback loop. Fixed: object changes are batched and processed once per game tick.[/*]
[*][b]Timing race with other mods[/b]: Items spawned by other mods during day start (Farm Type Manager, SVE, etc.) were missed. Fixed: grabbing is deferred by one tick so all mods finish spawning first.[/*]
[*][b]Missing mod building interiors[/b]: Only checked farm buildings, missing Ginger Island, SVE, and other modded building interiors. Fixed: all building interiors across all locations are checked.[/*]
[*][b]Debug log spam[/b]: Verbose logging was always on with no way to disable it. Fixed: debug logging is off by default with a config toggle.[/*]
[/list]
[/spoiler]

[color=#e69138][b]Global Grabber Modes[/b][/color]
[b]All mode:[/b] Designate one auto-grabber as the global grabber, open it and tap the [b]star button[/b] in the top-right of the menu (gold = designated, silver = not). Then press the fire key from anywhere to collect from all locations into that grabber. On mobile, enable [b]Auto-Fire Global Grabber[/b] so it runs automatically each morning, no hotkey needed.

[b]Hover mode (PC only):[/b] Hover your cursor over any auto-grabber and press the fire key. That grabber collects from every location.

You can also designate using the classic method: hover over a grabber and press G (or your configured designate key).

[size=4][b]FAQ[/b][/size]
[b]Can I install this mid-playthrough?[/b]
Yes. It works immediately on the next day.

[b]Does this replace Deluxe Grabber Redux 1.6?[/b]
Yes. Remove the old mod and install this one. This version fixes the bugs listed above and adds new features on top of the same foundation. Your config will need to be set up again since they use different mod IDs.

[b]Items aren't being collected in a specific location, what's wrong?[/b]
Check the Enabled Locations page in the config menu to make sure the location isn't disabled. Also check if Skip Festival Locations is blocking it.

[b]The auto-grabber chest is full, where do items go?[/b]
Items that don't fit are left for the next day. Grown crops just stay in the ground until the chest has room again, so your floor never gets covered in dropped crops (handy if you run a big greenhouse where one grabber can't hold the whole harvest). Consider using [url=https://www.nexusmods.com/stardewvalley/mods/43013]Bigger Auto-Grabber[/url] to expand the chest capacity, or place more than one grabber.
