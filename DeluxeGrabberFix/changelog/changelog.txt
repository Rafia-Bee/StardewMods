To be released

v1.23.0
- Added a "Grab on Placement" option. When it's on, a grabber you just placed collects nearby items right away instead of waiting for the next sweep, so you can keep the mod on Hourly or Daily without switching to Instant. Off by default.
- Improved config logging in the SMAPI log. When you save your settings, the log now shows just what changed instead of the whole config, which makes bug reports easier to sort out.
- Translators: see [url=https://github.com/Rafia-Bee/StardewMods/compare/DeluxeGrabberFix-v1.22.1...DeluxeGrabberFix-v1.23.0]i18n changes here[/url] (look at DeluxeGrabberFix/i18n/default.json).

v1.22.1
- Fixed crops piling up on the ground in big greenhouses when the auto-grabber chest was full. Once the chest fills up, the leftover grown crops now stay in the ground and get picked up later instead of being dumped on the floor.
- Fixed tea bushes planted in pots not being collected. The grabber now harvests potted tea along with potted crops like coffee.

v1.22.0
- Added Agromancy compatibility. Extra grapes (and bonus seeds) from yield-boosted crops now go straight into the auto-grabber instead of falling on the ground next to the trellis. No effect if you do not have Agromancy installed.

v1.21.1
- Fixed all grabbers (specialized and classic) silently stopping mid-session in v1.21.0. The new harvest interceptor would lock up if anything inside a vanilla harvest call ever threw (third-party Harmony patch, malformed crop, etc.), and every subsequent grab in the session aborted on the audit-4.6 reentry check. The interceptor is now exception-safe: every harvest call is wrapped in try/finally, and the grab session resets the interceptor flag when it ends so a leaked state never survives past one cycle.

v1.21.0
- Added modded-skill XP routing. When SpaceCore-based skill mods are installed, the grabber now grants XP for actions it performs on your behalf: Binning Skill (drbirbdev) gets credit for every town garbage can the grabber checks, and Archaeology Skill (moonslime) gets credit for every artifact spot dug up and every ore pan collected. Defaults match the upstream mods' own per-action XP. All toggles live on the Compatibility config page under "Modded Skill XP". No effect if the relevant mods aren't installed.
- Fixed global-mode routing always preferring older grabbers across maps over closer ones on the same map. Now if a Crop Grabber lives in the Greenhouse near a planted indoor pot, the harvest lands in that Greenhouse grabber instead of being shipped to a Farm grabber on the other side of the world. Same fix applies to wildflower, forage, seed-tree, and forage-hoedirt routing.
- Fixed tree debris (wood, sap, acorns) sitting on the ground for an in-game day in Instant mode. Cutting trees now triggers an hourly catch-up sweep so debris is collected within the hour instead of waiting for next day-start.
- Fixed ore pan items not appearing in the hourly HUD summary. Ore pan yield now shows alongside other grabbed items in the on-screen total when Report Yield is on.
- Fixed the HUD listing every named grabber on the map after a global grab, including ones that did not catch anything. Now only contributing grabbers are named.
- Fixed the GMCM Enabled Locations subpage bouncing back to the root every time you clicked Enable All, Disable All, or Select Visited Only. The subpage now stays open and the toggles update in place.
- Fixed Enable All silently re-skipping unvisited locations because Select Visited Only was still on. Clicking Enable All now also turns off Select Visited Only since the two intents contradict each other. Manually enabling a single unvisited location while SVO is on also now sticks.
- Fixed Seed Tree Grabber silently losing items when the chest was full. If the chest cannot fit a shaken item, it now drops on the ground next to the tree (matching how Indoor Pot, Forage HoeDirt, and Wildflower grabbers already handled overflow), instead of evaporating.
- Fixed Qi Beans dropped by shaken wild trees falling on the ground during Qi's Crop. The Qi Bean drop in Tree.shake routes through a different SDV method than the normal seed drop, which the interceptor was not patching. Qi Beans now route into the auto-grabber chest like every other shake-time drop. Same fix incidentally covers rare-spawn drops from shaken trees.
- Fixed double mail on retroactive Specialized progression. When the retroactive check grants a recipe you have already earned, you no longer also get the hint mail advertising a grabber you just unlocked.
- Improved diagnostics for mod-on-mod Harmony conflicts. If another mod's patch reenters a DGF grab cycle (e.g. Crop.harvest, Tree.shake), DGF now throws a clear exception naming the likely cause instead of silently dropping the outer grab's items.
- Reduced disk writes when warping with Select Visited Only on. Walking through 10 unvisited maps used to mean 20 disk writes; the writes are now coalesced and flushed at sleep or return-to-title. Note: force-quitting (alt-F4) before sleeping will lose any un-skipped maps from that day, matching Stardew's "no save = no persist" rule.
- Performance: machine-name cleaning is now memoized, GMCM rebuilds skip when nothing structural has changed, hourly grabs skip the diff pass when nothing was collected, day-start progression checks early-exit once all prerequisite types are owned. Several LINQ allocations on hot grabber paths replaced with foreach. Static caches now reset uniformly on title return.
- Internal refactors: consolidated machine grabber dispatch, yield-reporting, and config-swap plumbing so future bugs of these shapes are much harder to introduce. No user-visible change.

v1.20.4
- Fixed Specialized mode silently destroying off-type harvest targets. Placing only one type of specialized grabber (for example just a Forage grabber) no longer causes vanilla crops, indoor pot crops, spring onions, ginger, wildflowers, or seed trees on the same map to be harvested and dropped as ground debris. Sub-grabbers without a matching specialized grabber on the map are now skipped entirely, and crop tiles whose nearest matching grabber is out of range are left alone instead of being harvested into thin air.
- Fixed Classic mode + global grab not working with specialized grabbers. Designating a specialized grabber as the global grabber and pressing the fire-global-grab key now correctly deposits items into its chest. Previously every specialized grabber type reported "grabber is full" because the chest's external-add guard wasn't notified that a grab cycle was running.
- Internal refactor: consolidated grab-cycle state setup that was duplicated across nine event handlers into a single helper. No user-visible behavior change; future bugs of the same shape as the Classic-into-Specialized one above are now much harder to introduce.
- Reorganized config layout. Settings are now grouped (Features, Machines, Specialized, Locations, Global Grab, Compatibility) so the file is easier to navigate and adding new options is simpler. NOTE: your existing config.json will reset to defaults on first load. Use the in-game GMCM menu (or edit the new config.json) to restore your preferences.
